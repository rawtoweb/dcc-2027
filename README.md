# rawtoweb at the Data Curation Conference 2027

Cohort repository of the workshop "From raw data to a website for humans: a live curation workflow with every AI step disclosed" at the Data Curation Conference 2027, University of Basel, Thursday 14 January 2027, 10:45 to 12:00. Host: Lars Schöbitz, Global Health Engineering, ETH Zurich.

This repository holds what the participants touch on GitHub:

- The issue **Check in: your first contribution**, pinned. Step 2 of the pre-work, due on Friday 8 January 2027: everyone posts one comment there with one line on the kind of data they work with, without name and institution. It tests the GitHub account and shows where to type.
- On the day, the issues through which the room contributes to the dataset we build together.

Participants contribute through issues and comments only. Nobody edits files, makes a copy of the repository or joins an organisation, and nobody sends a dataset before the conference. `check-in-issue.md` holds the text of the check-in issue.

Everything else is on the workshop website, https://rawtoweb.github.io/website/dcc-2027/, and the record of the conference submission (abstract, session plan, AI disclosure) is in https://github.com/Global-Health-Engineering/workshop-dcc-2027.

# rawtoweb at the Data Curation Conference 2027

Cohort repository of the workshop "From raw data to a website for humans: a live curation workflow with every AI step disclosed" at the Data Curation Conference 2027, University of Basel, Thursday 14 January 2027, 10:45 to 12:00. Host: Lars Schöbitz, Global Health Engineering, ETH Zurich.

This repository holds two things for the participants:

- The issue **Check in**, pinned. Step 2 of the pre-work: everyone posts one comment there before the conference. It tests the GitHub account and shows where to type, because the dataset form, the review of each data package and the comment on the day all run through issues.
- The issue form **Submit a dataset**. Step 3 of the pre-work: participants submit a dataset here by Friday 11 December 2026, either their own data or a published dataset under CC BY 4.0 or CC0. Whoever has none says so in the survey. Each submission becomes an issue that tracks its data package.

Everything else is on the workshop website, https://rawtoweb.github.io/website/dcc-2027/, and the record of the conference submission (abstract, session plan, AI disclosure) is in https://github.com/Global-Health-Engineering/workshop-dcc-2027.

The data packages built from the submissions are separate repositories in this organisation, one per dataset. The data package built live in the workshop is one as well. On the day every participant posts one comment on the issue of one of these packages.
